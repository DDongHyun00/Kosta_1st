# 🎵 GPT 기반 감정에 따른 음악 추천 서비스

# 개요
사용자의 감정을 기반으로 상황에 어울리는 음악을 추천해주는 Java 콘솔 기반 프로젝트입니다.
단순한 감정 입력이 아닌 “오늘 시험 망쳐서 우울해” 와 같은 구체적인 상황을 입력받아 OpenAI ChatGPT API를 통해 감정을 분석하고, 그 감정에 맞는 노래를 추천합니다.
또한, 플레이리스트 관리 기능을 제공하여 감정 추천 기록을 저장하고 조회할 수 있도록 구성하였습니다.

# 🛠 주요 기능
감정 문장 입력 → GPT 기반 감정 분석

분석된 감정에 맞는 음악(제목, 아티스트, 유튜브 링크) 3곡 추천

추천된 음악 세트를 플레이리스트로 저장

사용자 회원가입 / 로그인 / 감정 추천 내역 조회

동일 감정 문장 중복 입력에 대한 추천 기록 관리

JDBC 기반 MySQL 연동 및 데이터 저장

# 👤 구현 내용
전체 시스템 설계 및 기능 구현

OpenAI ChatGPT API 연동 및 감정 분석 흐름 구현

감정 → 음악 추천 로직 및 결과 포맷 설계

JDBC 기반 DB 연동, 데이터 저장 구조 설계

콘솔 UI 메뉴 구성 및 흐름 처리

예외 처리 및 식별자 관리 로직 구현

# 🔧 사용 기술
Java : 전체 로직 및 콘솔 기반 UI 개발

OpenAI API : 감정 분석 및 텍스트 처리

MySQL : 사용자 정보 및 추천 결과 저장

JDBC : DB 연동 및 쿼리 실행

# ✈️ 주요 구현 기능
- 사용자 인터페이스	Java 콘솔 기반 UI로 회원가입, 로그인, 감정 입력, 음악 추천, 추천 리스트 조회 기능을 메뉴 선택 방식으로 구현
- 감정 분석	OpenAI ChatGPT API 연동으로 입력 문장을 분석, 핵심 감정을 추출하여 추천 기준으로 활용
- 음악 추천	GPT 응답 파싱을 통해 감정별 노래 제목/아티스트/유튜브 링크를 3곡씩 추천
- 데이터 저장	JDBC 기반 MySQL 연동으로 사용자, 감정 입력, 추천 결과를 저장 및 재조회 가능
- 정규화	감정당 3곡을 1세트로 저장해 1정규형 충족, 추천 리스트는 세트 단위로 관리
- 식별자 관리	playlist_number 필드로 동일 감정 문장 중복 추천도 구분 가능
- DB 연동	기능별 쿼리를 모듈화하고 예외 처리 적용으로 안정성 확보
- 예외 처리	로그인 실패, 입력 누락, API 실패 등 다양한 예외 상황을 방어적 프로그래밍으로 처리
- 확장성	Music 테이블을 분리하지 않고 세트 단위 관리 → 추후 곡 단위 테이블로 확장 가능
